# Requisitos Funcionais

| RF         | Descrição                                                                                              |
|------------|--------------------------------------------------------------------------------------------------------|
| **RF0001** | O sistema deve permitir a criação de chats do tipo `PRIVATE` entre dois usuários distintos.            |
| **RF0002** | O sistema deve permitir a criação de chats do tipo `GROUP` com múltiplos participantes.                |
| **RF0003** | O sistema deve permitir que participantes deixem um chat voluntariamente.                              |
| **RF0004** | O sistema deve permitir que administradores adicionem participantes a um chat do tipo `GROUP`.         |
| **RF0005** | O sistema deve permitir que administradores removam participantes de um chat do tipo `GROUP`.          |
| **RF0006** | O sistema deve permitir que administradores alterem o título e a descrição de um chat do tipo `GROUP`. |
| **RF0007** | O sistema deve permitir a consulta de um chat pelo seu identificador.                                  |
| **RF0008** | O sistema deve permitir a consulta dos chats dos quais determinado usuário participa.                  |
| **RF0009** | O sistema deve permitir a identificação da role de cada participante dentro do chat.                   |
| **RF0010** | O sistema deve permitir que o usuário faça login                                                       |
| **RF0011** | O sistema deve permitir que o usuário faça o cadastro                                                  |
| **RF0012** | O sistema deve permitir que o usuário altere seus dados                                                |
| **RF0013** | O sistema deve permitir que participantes do chat enviem mensagens                                     |
| **RF0014** | O sistema deve permitir que participantes do chat possam editar e excluir mensagens                    |
